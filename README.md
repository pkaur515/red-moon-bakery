# Red Moon Bakery & Cafe - Website

A modern, high-converting website for Red Moon Bakery & Cafe located in Mississauga, Ontario.

## Features

### 🎯 Design Elements
- **Hero Section**: Eye-catching banner with rating (4.8★ out of 232 reviews), headline, and dual CTAs (pickup/delivery)
- **Navigation Bar**: Sticky navigation with smooth scrolling and mobile hamburger menu
- **About Section**: Company story, value proposition, and key features
- **Services Menu**: 6 showcase cards for cakes, pastries, biscuits, coffee, cupcakes, and gift boxes
- **Testimonials**: Customer reviews with avatars and ratings
- **Contact & CTA**: Multiple ways to order with location, phone, and directions
- **Footer**: Business information and contact details

## Customization Guide

### Update Business Info
Edit the following in `index.html`:
- Address: 4025 Brandon Gate Dr, Mississauga, ON L4T 3Z9
- Phone: (942) 588-4545
- Business hours
- Service descriptions

### Change Colors
Edit these variables in `styles.css`:
```css
:root {
    --primary-color: #d4454e;      /* Main red color */
    --secondary-color: #2c2c2c;    /* Dark gray */
    --accent-color: #f5deb13;      /* Light gold */
    --light-bg: #fafafa;           /* Light background */
    --white: #ffffff;              /* White */
    --gray: #6b6b6b;               /* Medium gray */
}
```

### Add Real Images
Replace emoji placeholders (🍰, 🧁, etc.) with real product images:
1. Upload images to your project
2. Create an `images/` folder
3. Update HTML to use `<img>` tags instead of emojis
